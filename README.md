# Boys Golf Trip 2027

Team Blue vs Team Green. June 15 to 18, 2027, Sandhills, NC.

A single-file site: countdown, tee sheet with matchups, prize pool, trip MVP, cup standings and rosters.

## Hosting
Served as a static site with GitHub Pages. In the repo, go to Settings, then Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.

## Editing
Everything is data in the script at the bottom of `index.html`. See `CLAUDE.md` for the structure and the current open items.
