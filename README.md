# Boys Golf Trip 2027

Team Blue vs Team Green. June 15 to 18, 2027, Sandhills, NC.

A single-file site: countdown, tee sheet with matchups, live scoring view, prize pool, trip MVP, cup standings and rosters.

## Hosting
Served as a static site with GitHub Pages. In the repo, go to Settings, then Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.

## Editing
Scores, matchups, formats and prize winners are in the `trip-data` JSON block near the bottom of `index.html`; fixed facts are in the script after it. See `CLAUDE.md` for the structure and the current open items.

Live URL: https://youngdesi2.github.io/golf-trip/
